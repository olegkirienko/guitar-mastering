# Етап I — Звук

## Центральне питання
> Що відбувається від моменту, коли ми смикаємо струну, до моменту, коли чуємо звук?

## Результат
Учень пояснює:
`струна → коливання → середовище → звукова хвиля → вухо → мозок`,
розрізняє частоту, висоту й тембр та розуміє, від чого залежить частота струни.

## Вузол 1. Що таке звук?
**Досвід:** смикнути басову струну, побачити коливання, потім зупинити її пальцем.

**Питання:** що робить струна, поки звучить? Чому після зупинки звук припиняється? Як рух доходить до вуха?

**Відкриття:** струна змушує коливатися середовище; збурення поширюється як хвиля.

**Поняття:** коливання, положення рівноваги, середовище, звукова хвиля.

**Інтерактив:** анімована струна → хвиля → «Зупинити струну».

**Нове питання:** чому звуки бувають високими й низькими?

## Вузол 2. Частота і висота
**Досвід:** відкрита перша струна → та сама струна, затиснута вище.

**Відкриття:** кількість повних коливань за секунду — **частота**, одиниця — Hz.

`більша частота → вищий pitch`, `менша → нижчий`.

**Контрприклад:** та сама нота тихо/голосно — висота не змінюється.

**Інтерактив:** frequency slider + хвиля + Web Audio tone.

## Вузол 3. Від чого залежить частота струни?
За інших рівних умов:
- коротша струна → вища частота;
- більший натяг → вища;
- більша лінійна густина → нижча.

### Копнути глибше
`f = (1 / 2L) × √(T / μ)`

Формула optional; причинна модель — обов'язкова.

**Інтерактив:** Length / Tension / Linear density; спочатку прогноз, потім експеримент.

## Вузол 4. Тембр
**Проблема:** гітара і піаніно можуть мати однаковий pitch, але звучать по-різному.

**Відкриття:** основна частота не описує звук повністю.

**Поняття:** основна частота, обертони/часткові, спектр, атака, згасання, тембр.

**Інтерактив:** одна fundamental + додавання гармонік.

## Фінальна лабораторія
1. Зробити віртуальну струну вищою без зміни густини.
2. Зробити нижчою без зміни довжини.
3. Створити два звуки однакової висоти, але різного тембру.
4. Пояснити шлях від струни до слухового сприйняття.
