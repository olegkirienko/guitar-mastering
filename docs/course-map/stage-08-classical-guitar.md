# Етап VIII — Музична мова і класична гітара

## Центральне питання
> Як перетворити розуміння звуку, ритму, мелодії та гармонії на осмислене виконання класичної гітари?

## Принцип
Це не «кінець теорії й початок практики». Практика йшла весь курс.

`слух + читання + техніка + музичне мислення → виконання`

## Результат
Учень має базову посадку й техніку, читає просту стандартну нотацію, співвідносить її з грифом, грає мелодію, бас та прості арпеджіо і може осмислено вивчити короткий початковий твір.

## Вузол 1. Посадка
Досліджуємо стабільність, нейтральні положення кистей, свободу плечей та мінімум зайвої напруги.

Не шукаємо одну «фотографічно правильну» позу для всіх тіл.

## Вузол 2. Права рука
Позначення:
`p — pulgar, i — índice, m — medio, a — anular`.

Починаємо з відкритих струн:
- стабільне положення;
- i–m alternation;
- p на басах;
- контроль атаки;
- якість звуку.

Спершу tirando; apoyando додаємо як окремий спосіб звуковидобування.

## Вузол 3. Ліва рука
Експеримент: знайти **мінімальний** тиск, за якого нота чиста.

Навички: пальці 1–4, позиція біля ладу, великий палець без «лещат», підготовка наступного руху.

## Вузол 4. Навіщо нотація?
Нотація передає висоту, час, метр, фразування, динаміку й виконавські вказівки.

Базово: нотний стан, скрипковий ключ, нота, додаткові лінійки, тактові риски.

## Вузол 5. Папір → гриф
Не вчимо весь стан одразу.

`відкриті верхні струни → кілька нот першої позиції → короткі мелодії → розширення`.

Цикл:
`побачив → назвав → знайшов → передбачив → зіграв → почув`.

## Вузол 6. Ритм + висота
Для нового фрагмента:
1. окремо ритм;
2. окремо ноти;
3. повільне поєднання;
4. потім темп.

## Вузол 7. Мелодія
Короткі одноголосні фрази: рівний пульс, i–m, чиста ліва рука, напрям фрази, слухання власного tone.

## Вузол 8. Бас + мелодія
`p` веде бас, `i/m` — верхній голос.

Мета — почути два голоси, а не лише виконати рухи.

## Вузол 9. Арпеджіо
Повертаємо гармонію Етапу VII.

Прості patterns: `p-i-m-a`, `p-i-m-i`, `p-m-i-m`, завжди в реальному музичному контексті.

## Вузол 10. Музичність
Одна фраза з однаковими нотами й ритмом може звучати по-різному.

Поняття: dynamics, articulation, phrase, tone color, direction.

## Вузол 11. Перший завершений твір
Процес:
1. форма;
2. метр/ритм;
3. ноти й позиції;
4. знайомі інтервали/акорди;
5. аплікатура;
6. фрази;
7. повільна практика;
8. з'єднання;
9. запис;
10. самооцінка.

Ключове питання змінюється з «куди поставити палець?» на «що тут відбувається музично і як я хочу, щоб це прозвучало?»

## Паралельна технічна доріжка
Протягом подальшого навчання: alternation, string crossing, coordination, scales, arpeggios, slurs, barre, shifts, tone production, independence of voices.

## Фінальний checkpoint
Новий короткий твір: прочитати структуру, проплескати ритм, знайти ноти, побачити знайомі структури, вибрати базову аплікатуру, вивчити фразами, виконати й пояснити музичну логіку.

## Далі — Level 2
Key signatures → harmonic/melodic minor → cadences → inversions → voice leading → складніші ритми → позиційна гра → barre → legato → поліфонія → інтерпретація → ширший репертуар.
