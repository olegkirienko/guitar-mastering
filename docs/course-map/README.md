# Guitar Mastering — педагогічна карта курсу

Це педагогічний **source of truth** курсу. Документи описують логіку навчання, а не UI.

## Цикл кожного уроку

```text
ДОСВІД → ПИТАННЯ → СПОСТЕРЕЖЕННЯ → ЗАКОНОМІРНІСТЬ
       → ПОНЯТТЯ + НАЗВА → ЕКСПЕРИМЕНТ НА ГІТАРІ
       → ЗАСТОСУВАННЯ → НОВЕ ПИТАННЯ
```

Ми не починаємо з визначення, якщо учень може спочатку зустрітися з явищем.

## Чотири паралельні доріжки
- **Розуміння:** чому це так?
- **Слух:** що я чую?
- **Руки:** чи можу я це зіграти?
- **Дослідження:** чи можу передбачити результат і перевірити його?
